# DSpark undrafted status default

Pure undrafted DSpark decode joins saved status in one packet by default.
Eligible native device-result steps submit private sampling before that
readback and complete every Engram gather before returning success.
Mixed, prefill and drafted steps keep their existing boundaries. Small
packets retain per-rank validation, and failed validation prevents commit
and result publication.

The pinned DSpark fixtures execute prefill and host-supplied verification.
With device results enabled by default, they prepare one private readiness
event per rank. The declaration binds those four events in each of the six
TP4 verify fixtures. Every retained full-history operation and pinned body
is identical under the ordered typed handle map. No operation edit or
module change is declared.

Creator positions are authored from instrumented archive traces and checked
against the sealed captures. The frozen journal-proof generator checks the
empty operation delta, and the proof reads the declaration at this commit.
The undrafted ready-result tests exercise the joined packet, sampling order,
capacity boundary, status errors, gather failure and terminal commit behavior.

Served exactness and step-time comparisons cover this default together with
indexed retention and calibrated verify allocation. Regenerate positional
declarations whenever preceding creation changes.
