# Retired one-launch HC boundary

[The declaration](c18-retired-hc-boundary.json) permits removal of only the
retired HC completion module and its resolves. No instance loads this module;
the column-block pair serves its former buckets.

The complete ten-entry catalog and byte-identical lock pair move to the model
lab. `build_family lab/sinkhorn_hc_completion_reference` rebuilds the original
cubin against that lock. The catalog test remains with its declaration, and
the bundle preserves its completion comparison and no-load assertion.

The declaration names the removed package module directly. The journal proof
reads it at the retirement commit and checks every other captured operation.
Every retained package cubin is audited against the previous locked bytes.
