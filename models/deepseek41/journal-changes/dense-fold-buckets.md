# Dense fold interval simplification

The declaration enumerates 104 shape/row cells whose existing ticket
schedule becomes the prefetch schedule already used inside the same
interval. Each cell selects an initialize symbol and a compute symbol.
Rows 1 through 8 and the unresolved N5120/K15360 interval stay unchanged.

The row count is argument 6 of initialize and argument 10 of compute.
Selectors read those scalar arguments in the base journal. Matching cases
replace only the symbol. Every argument, grid, block, workspace, module,
resolve, launch count and operation order remains unchanged.

The cases were generated from the selected table-cell differences and the
explicit symbols recorded by the schedule-pair lab. Both devices passed
all changed cells bitwise, with eight poisoned eager/graph comparisons
and a null-launch negative control. Each selected timing gain exceeded
its in-job A/A excursion. Lab timing does not establish served acceptance.

substitutions across eight pinned journal names and no create or auxiliary
history changes. Four pinned-journal tests match those predictions. The
committed declaration must also pass the frozen journal proof helper
against authenticated base and head captures. Served bitwise and
