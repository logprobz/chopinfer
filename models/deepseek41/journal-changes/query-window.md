# Query-window journal declaration

The test default now uses the served one-row query-window twins. The
declaration activates four loads of the unchanged locked module and its
two resolves per load in the affected Flash TP4 fixtures. It names graph
handles whose node counts shrink and the exact launch substitutions in
the native media decode history. The source audit derives each twin's
arguments from the original query and window operations and checks graph
node counts and every retained operation.

Creator declarations were derived from sealed adjacent-commit captures,
constrained to the resources above. `tools/journal_proof/specs/operation_edits.py`
generated the compact exact operation edits. The edits were reviewed
against source-derived history audits. `layout_spec.py` and `proof.py`
read this declaration from the flip commit and check all pinned journals,
creation records and device history through each last pinned checkpoint.
